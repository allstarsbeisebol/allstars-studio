Abrir produção no GitHub (opcional)

Os arquivos gerados são prévias editoriais: antes de postar no Instagram, confira os fatos, a qualidade da narração e os direitos de uso. O sistema não publica automaticamente.

Como funciona

1. O GitHub seleciona uma história não produzida.
2. O Piper cria a narração; o FFmpeg gera o Reel.
3. O vídeo, a narração, o roteiro e a legenda ficam disponíveis para baixar aqui.

A biblioteca inicial é limitada e a pesquisa histórica ainda não é totalmente automática. Se faltar uma história inédita, o sistema sinalizará, em vez de repetir.
